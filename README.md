# Minecraft Time Bank

A phone app for tracking Minecraft time: add or remove minutes, run a countdown play timer, and see a 7-day chart of time played vs. earned.

Open the GitHub Pages link on your phone, then:
- **iPhone (Safari):** Share button → **Add to Home Screen**
- **Android (Chrome):** ⋮ menu → **Install app** / **Add to Home screen**

Works offline. Data is saved on the phone.
